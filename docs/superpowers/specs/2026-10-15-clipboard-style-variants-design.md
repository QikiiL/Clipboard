> 日期：2026-10-15 ｜ 仓库：`D:\copy\clipboard-manager-tauri` ｜ 基线提交：`edfafd8`（v1.3.0，工作区干净）
>
> **交付定位**：本规格是**阶段性交付**，用来把"三套风格长什么样、原型要满足什么"写到可实现、可验收的粒度。

## 1. 目标

在不改现有软件的前提下，产出一个可点击的并排静态原型，让用户从三套全新风格中选定一个方向。

| 代号 | 名称 | 参考 | 方向 |
|---|---|---|---|
| A | 瑞士索引 | Müller-Brockmann 网格体系 | 浅灰白底、清晰分隔、醒目序号、少量朱红 |
| B | 石墨控制台 | Territory Studio 信息层级 | 深石墨底、紧凑列表、克制荧绿状态（**无科幻装饰**） |
| C | 雾绿工作台 | Takram 柔和技术 | 浅矿物灰 + 雾绿、舒展行距、明度而非描边分区 |

硬约束：每套展示**主面板 + 设置面板**；可点**场景 / 深浅 / 并排比较**；
`搜索 / 分组 / 收藏 / 连续粘贴` 四个入口**位置不变**；示例内容**不读取真实剪贴板**；
品牌现状是 **Tauri 默认图标**，**不得伪造新 logo**。

## 2. 范围

**做**：本规格文档；随后（阶段 2）单 HTML 静态原型。

**不做**：不改 `src/`、`src-tauri/`、`index.html`、`package.json`、`globals.css`、Tailwind 令牌；
不加依赖与构建步骤；不读写真实剪贴板、不调 Tauri API；不实现设置项真实逻辑（开关只切视觉状态）；
不产出 logo / 字标 / 图标；不删除工作区根 `D:\copy\ui-redesign\` 的 7 个旧预览；
不做列表方向键导航、拖拽排序、多选批量删除；不追求与生产实现像素级一致；
**不在本规格内选定最终风格**（由用户看原型后决定）。

## 3. 现状基线（只读检查结论）

- 面板渲染顺序固定（`src/App.tsx`）：标题栏 46px → 搜索 → 分组页签 → 连续粘贴横幅（条件）→ 列表 → 状态栏 36px → 设置模态。设计基准 **420×520**。
- 断点是**容器查询**（`globals.css:81-84`）：`narrow < 360px`、`wide ≥ 520px`；组件用 `@max-narrow:` / `@min-wide:`。
- 设置面板是**居中模态**，6 个分区固定：外观 / 通用 / 快捷键 / 隐私 / 数据 / 关于（`SettingsPanel.tsx`）。
- 现有令牌：`--bg --surface --text --muted --faint --hair --accent --accent-deep --accent-soft --accent-ring --star --ok --warn --warn-text --danger --on-accent --lift --lift-hover --dialog-shadow`；字体栈 `'Segoe UI Variable Text', 'Segoe UI', 'Microsoft YaHei UI', system-ui`。
- 行结构：类型图标列 26px + 内容 + 右侧（收藏星 / 分组图标 / 相对时间 / 悬停展开的 4 个操作按钮）。
- Escape 是**分层的**（搜索框聚焦 → 设置模态 → 模态内确认，逐层消费），**禁止全局单点处理**。
- 品牌证据：`src-tauri/icons/` 是 Tauri 默认图标集；`index.html` 引用 Vite 默认 `/vite.svg`；界面标题是纯文本「剪贴板」，无字标。

## 4. 三套风格辨识

三套**共用同一份布局骨架、同一份示例内容、同一套点击行为**，差异只在视觉层——这是并排比较有意义的前提。

| 维度 | A 瑞士索引 | B 石墨控制台 | C 雾绿工作台 |
|---|---|---|---|
| 底色 | 浅灰白（暖中性） | 冷灰石墨（**深色为主态**） | 浅矿物灰（极淡绿） |
| 分区手段 | 贯穿全宽的分隔线 | 紧凑行 + 行首状态圆点 | **明度分层 + 间距**（无描边） |
| 圆角 / 行高 / 行距 | 2px / 52px / 1.45 | 6px / **40px** / 1.35 | 14px / **60px** / **1.7** |
| 唯一强调色 | 朱红 `hue 30` | 荧绿 `hue 152`（**仅状态语义**） | 雾绿 `hue 168`（彩度 ≤ 0.09） |
| 阴影 | 无（仅模态） | 无（内描边） | 浅色柔和投影 / 深色明度分层 |
| 数字 | 序号栏等宽两位 | **全量等宽 tabular-nums** | 常规比例数字 |

### 4.2 组件要点

- **A**：序号栏 34px 宽（`01`–`10`，等宽）；行间 1px 线**贯穿全宽**、行间距 0；选中行＝**序号栏数字变朱红 + 中性底 `--surface-2`**（不用竖条、不用 ring）；页签是**直角分段控件**（非 pill），选中＝底纹 + 文字朱红 + 2px 下划线；全界面无阴影（模态除外）、无 pill、**无任何侧边强调条**。
- **B**：每行**行首 6px 状态圆点**（默认＝中性暗点 / 选中＝中性亮点 `--select-rule` / 已粘贴＝荧绿 / 暂停＝琥珀）；所有数字等宽 tabular-nums；分区头与状态栏用 10px、字距 0.16em 微标签；页签是紧凑 pill，选中＝中性填充（**不用绿**）；荧绿只出现在监听中圆点、已粘贴圆点、输入焦点三处。
- **C**：行**无描边、无侧边竖条**，圆角 14px，行间 12px 间隙，靠 `--bg` 与 `--surface` 的明度差分区；选中＝**仅明度变化**（升到 `--surface-2` 底）；页签是低对比 pill（无下划线无描边）；空状态上下留白 64px、行距 1.8；设置卡片去掉描边，仅保留低对比行内细线。

### 4.3 方向辨识锚点（浅深两态都必须成立）

| A | B | C |
|---|---|---|
| A1 圆角 2px（近直角） | B1 行高 40px，一屏 ≥9 行 | C1 行无描边、无侧边竖条，找不到"卡片边框" |
| A2 行左 34px 两位序号栏 | B2 所有数字等宽 tabular-nums | C2 行高 60px、行距 1.7、间隙 12px |
| A3 行间贯穿全宽的 1px 线 | B3 行首 6px 状态圆点（选中＝中性亮 / 已粘贴＝荧绿 / 暂停＝琥珀） | C3 雾绿唯一且彩度 ≤ 0.09，只出现在收藏星 / 焦点环 / 监听状态点 |
| A4 朱红只出现 4 处：选中页签 / 选中行序号 / 收藏星 / 焦点环 | B4 10px、字距 0.16em 微标签 | C4 圆角统一 14px，靠明度/柔和投影分层 |

**跨态规则**：浅深两态共享**布局、间距尺度、字号阶梯、锚点结构**，只变色值与阴影策略。禁止"一进深色三套就长得一样"。

## 7. 浅深两态

- 每套风格独立浅深令牌（§4.1），切换**只影响本列**。
- 两态都必须满足 §4.3 锚点清单——**这是"保留方向辨识"的验收依据**。
- B 的深色是主态，浅色是「日间控制台」：冷灰底（非白）+ 荧绿压暗到 `50% 0.13 155` 保证浅底对比，锚点 B1–B6 全部保留。
- C 的深色把柔和投影换成明度分层 + 极淡内描边，锚点 C1–C6 全部保留。
- 对比度：正文 ≥ 4.5:1；大字号与图形边界 ≥ 3:1；强调色上的文字 ≥ 4.5:1。

## 8. 原型架构

```
clipboard-manager-tauri/docs/superpowers/
├─ specs/2026-10-15-clipboard-style-variants-design.md   ← 本规格
└─ previews/clipboard-style-variants/index.html          ← 单文件原型（HTML + CSS + JS 全内联）
```

- **单 HTML 文件，零依赖、零构建**：不使用 CDN、不下载字体、不引框架或图标库；双击 `file://` 即可打开。图标全部内联 SVG `<path>`（数据照抄 `src/components/icons.tsx`，不重绘）。
- **放仓库内**（而非工作区根 `ui-redesign/`）：仓库是 git 仓库可版本化；`docs/` 不在 Vite 构建输入链；`git check-ignore` 已确认未被忽略。工作区根旧预览**保留不动**。
- **隔离不用 iframe**：靠 `[data-variant]` 作用域 CSS + 每列独立 `state` 对象 + 事件委托到列根。**全文件禁用 `id`**（3 份重复 id 会互相污染），一律 `data-*` + `closest()`。
