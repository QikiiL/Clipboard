## 1. 背景与用户需求

现有 UI 是「方案 D · 浮笺」：浅灰白底 + 细描边卡片 + 蓝色强调（`src/styles/globals.css`）。
需要在不改动现有软件的前提下，先做**可点击的并排预览**，从三套全新风格里挑一个方向。

三套方向（用户指定参考，但都不照搬参考对象的装饰）：

| 代号 | 名称 | 参考 | 一句话方向 |
|---|---|---|---|
| A | 瑞士索引 | Josef Müller-Brockmann 的网格体系 | 浅灰白底、清晰分隔、醒目序号、少量朱红 |
| B | 石墨控制台 | Territory Studio 的信息层级 | 深石墨底、紧凑列表、克制荧绿状态（**不要科幻装饰**） |
| C | 雾绿工作台 | Takram 的柔和技术 | 浅矿物灰 + 雾绿、舒展行距、明度而非卡片描边分区 |

需求硬约束（来自用户）：

1. 每套风格展示**主面板 + 设置面板**两个界面。
2. 可点：**场景切换**、**深浅模式切换**、**并排比较**。
3. `搜索 / 分组 / 收藏 / 连续粘贴` 四个入口**保留原位**。
4. 示例内容**不读取真实剪切板**，全部硬编码。
5. **不是接入生产应用**——预览与 `src/` 完全解耦。
6. 每套风格都要有浅深两态，且**两态都必须保留该风格的方向辨识度**（不能一进深色就三套长得一样）。
7. 品牌现状是 **Tauri 默认图标**，**不得伪造新 logo**。

## 3. 现状基线（只读检查结论）

以下事实全部来自对当前仓库的只读检查，是设计必须贴合的地基。

### 3.1 面板结构与位置（`src/App.tsx`）

渲染顺序固定，这就是「入口保留原位」的基准：

```
<div class="@container flex flex-col h-screen bg-app text-ink">
  <header>            46px（窄 40 / 宽 52）  标题「剪贴板」+ 置顶/保持打开/连续粘贴/设置 | 最小化/最大化/关闭
  <SearchBar />       px-4 pt-3 pb-2.5，输入框高 36（窄 32 / 宽 40）
  <GroupTabs />       全部 | 收藏 | 各分组 | + 新建分组（pill 容器，横向滚动）
  <ContinuousPasteBar />   仅框选模式存在时渲染
  <ClipboardList />   flex-1，虚拟滚动，行用 top 定位
  <StatusBar />       36px（窄 32 / 宽 40）
  <SettingsPanel />   模态，isOpen 时才渲染
</div>
```

- 设计基准尺寸 **420×520 逻辑像素**（`window_sizing.rs` 的 `DESIGN_W/H`）。
- 断点用**容器查询**而非视口查询：`--container-narrow: 22.5rem (360px)`、`--container-wide: 32.5rem (520px)`；组件用 `@max-narrow:` / `@min-wide:` 命中（`globals.css:81-84`）。
- 设置面板是**居中模态**：`fixed inset-0 z-50 bg-black/50` + `max-w-md max-h-[90vh]` 卡片，body 内滚动（`SettingsPanel.tsx:410-411`）。
- 设置分区固定 6 个：**外观 / 通用 / 快捷键 / 隐私 / 数据 / 关于**（`SettingsPanel.tsx:431,439,492,561,736,771`）。

### 3.2 现有令牌（`globals.css`）

`:root`（浅）与 `.dark`（深）各一套，映射进 Tailwind `@theme inline`：

`--bg --surface --text --muted --faint --hair --accent --accent-deep --accent-soft --accent-ring --star --ok --warn --warn-text --danger --danger-deep --on-accent --lift --lift-hover --dialog-shadow`

字体栈：`'Segoe UI Variable Text', 'Segoe UI', 'Microsoft YaHei UI', 'PingFang SC', system-ui, sans-serif`。
主题切换：`html.dark` 类 + `localStorage['theme']`，无存储时跟随 `prefers-color-scheme`（`ThemeContext.tsx`）。

### 3.3 行与空状态现状

- 条目行：`min-h-[52px] p-[10px] rounded-[10px]`，类型图标列 26px，右侧依次 收藏星 / 分组图标 / 相对时间 / 悬停展开的 4 个操作按钮（预览·收藏·分组·删除，宽 118px）（`ClipboardItem.tsx:342,399`）。
- 空状态分 4 个场景：搜索无结果（带「清空搜索」按钮）/ 收藏为空 / 空分组 / 无任何记录（`ClipboardList.tsx:100-147`）。
- 状态栏左：`N 条 · N 收藏 · 存储大小(仅宽屏) · v版本`；右：`单击粘贴/单击复制` 胶囊 + 监听状态圆点（`StatusBar.tsx:147-192`）。
- 状态栏另有 2 类居中提示卡（共用同一容器堆叠）：排除规则命中（8 秒，可「仍要记录」）、验证码已复制（8 秒，可「知道了」）（`StatusBar.tsx:203-266`）。
- 连续粘贴横幅三段式：框选阶段 / 执行阶段 / 完成阶段（`ContinuousPasteBar.tsx:120-211`）。

### 3.4 键盘现状（必须复刻的分层语义）

- `Ctrl+F` 聚焦搜索框；`Escape` **仅在搜索框聚焦时**清空并失焦（`SearchBar.tsx:24-39`）。
- 设置面板 `Escape` 关闭；但「清空历史」确认打开时**先关确认**（`SettingsPanel.tsx:161-176`）。
- 连续粘贴框选阶段：焦点在 `body` 时 `Enter` 开始连续粘贴（`ContinuousPasteBar.tsx:79-99`）。
- 代码注释明确警告：**不要把 Escape 处理搬到全局**，会一次按键触发两个动作。

### 3.5 品牌现状（不得伪造）

| 事实 | 证据 |
|---|---|
| 应用图标是 **Tauri 默认图标集** | `src-tauri/icons/` 下 `32x32.png`、`128x128.png`、`128x128@2x.png`、`icon.icns`、`icon.ico`、`icon.png`、`Square*Logo.png`、`StoreLogo.png` —— 与 Tauri 脚手架默认产物一致，无自定义标识 |

| 产品名 | `tauri.conf.json`：`productName: "clipboard"`、`identifier: "com.lyz.clipboard-manager-tauri"`、`version: "1.3.0"` |
| 界面内标题 | 纯文本「剪贴板」，无字标（`App.tsx:172-174`） |

**规格强制**：预览中出现的应用标识，只能是对 `src-tauri/icons/128x128.png` 的**原样字节引用**；不得重绘、不得加滤镜/描边/渐变/圆角裁切、不得生成新字标、不得把某套风格的强调色（朱红/荧绿/雾绿）画成符号充当图标。需要文字标识时只用产品名「剪贴板」+ 与 `globals.css` 相同的系统字体栈。

## 4. 三套风格总览

三套风格**共用同一份布局骨架、同一份示例内容、同一套交互行为**，差异只在视觉层。这是并排比较有意义的前提。

| 维度 | A 瑞士索引 | B 石墨控制台 | C 雾绿工作台 |
|---|---|---|---|
| 底色倾向 | 浅灰白（暖中性） | 冷灰石墨（**深色为主态**） | 浅矿物灰（极淡绿） |
| 分区手段 | 贯穿全宽的分隔线 | 紧凑行 + 左侧状态轨 | **明度分层 + 间距**（无描边） |
| 圆角 | 2px（近直角） | 6px | 14px |
| 列表行高 | 52px | **40px（最紧凑）** | **60px（最舒展）** |
| 行间距 | 0（线分隔） | 2px | **12px** |
| 正文字距 | 1.45 | 1.35 | **1.7** |
| 唯一强调色 | 朱红 `hue 30` | 荧绿 `hue 152`（**仅状态语义**） | 雾绿 `hue 168`（低彩度） |
| 阴影策略 | 无（仅模态有） | 无（内描边） | 浅色柔和投影 / 深色明度分层 |
| 数字处理 | 序号栏等宽两位零填充 | **全量等宽 tabular-nums** | 常规比例数字 |
| 方向辨识锚点 | A1–A6 | B1–B7 | C1–C6 |

**跨态规则（三套通用）**：浅深两态必须共享**布局、间距尺度、字号阶梯、锚点结构**；只有色值与阴影策略改变。每套风格的锚点清单（第 7 节）在浅深两态都要逐条成立。

## 8. 预览架构

### 8.1 文件落点

```
clipboard-manager-tauri/
└─ docs/
   └─ superpowers/
      ├─ specs/
      │  └─ 2026-10-15-clipboard-style-variants-design.md   ← 本规格（已提交）
      └─ previews/
         └─ clipboard-style-variants/
            ├─ index.html          ← 单文件原型（HTML + CSS + JS 全内联）
            └─ assets/
               └─ icon-128.png     ← 字节级复制自 src-tauri/icons/128x128.png
```

**为什么放仓库内**（而不是沿用工作区根的 `D:\copy\ui-redesign\`）：

1. 仓库是 git 仓库，预览可版本化、可回溯；`D:\copy` 根目录不是 git 仓库。
2. `docs/superpowers/` 未被 `.gitignore` 忽略（已用 `git check-ignore` 验证，退出码 1＝未忽略）。
3. `docs/` 不在 Vite 的构建输入链（`index.html` 只引 `/src/main.tsx`），预览不会被误打进产物。
4. 工作区根 `ui-redesign/` 的 7 个旧文件是**历史参考**，本规格要求**保留不动**，新的预览与它并存。

预览目录随「步骤 2」的实现一并提交——它是设计交付物，不是构建产物。

### 8.2 技术形态：单 HTML 文件

- **一个文件**：`index.html`。`<style>` 与 `<script>` 全部内联。
- **零依赖**：不使用 CDN、不下载字体、不引图标库、不引框架（无 React、无 Tailwind CDN）。
- **零构建**：双击 `file://` 直接打开即用；不启动 dev server；不新增 npm script。
- **图标**：全部内联 SVG `<path>`，数据照抄 `src/components/icons.tsx`（不重绘、不改线条）。
- **品牌图标**：`assets/icon-128.png` 是 `src-tauri/icons/128x128.png` 的**字节级副本**，用 `Get-FileHash` 验证两文件 SHA-256 一致。

### 8.3 单文件内部结构（顺序固定）

1. `<head>`：`<meta charset="utf-8">`、`<meta name="viewport">`、`<title>剪贴板 · 三套风格变体预览</title>`、内联 `<style>`。
2. 预览器外壳令牌：`:root`（页面背景、比较器间距、列宽），独立于三套风格。
3. **6 个风格令牌块**：`[data-variant="a"][data-theme="light"]`、`a/dark`、`b/light`、`b/dark`、`c/light`、`c/dark`，每块声明 §7 的完整令牌集。
4. 组件层样式：`.panel .hdr .search .tabs .cpbar .list .row .status .modal .row-actions .log` 等，**全部**以 `[data-variant=...]` 或 `[data-theme=...]` 作用域限定；禁止裸类名跨变体生效。
5. 断点：面板框 `container-type: inline-size`，用 `@container panel (max-width: 22.5rem)` / `@container panel (min-width: 32.5rem)` 复刻生产的容器查询三档。
6. 静态 HTML 骨架：比较器头部（说明 + 全局控件）+ 3 个 `<section class="col" data-variant="a|b|c" data-theme="light">`；每列内是**完整的默认场景（S1）静态 DOM**——12 行列表、页签、搜索框、状态栏、隐藏的设置模态。
7. `<script>`：一个工厂 `createPanel(rootEl, variantId)`，实例化 3 次；含 `state`、`render()`、事件委托、场景渲染、主题切换、宽度切换、键盘处理、活动日志。

### 8.4 隔离与状态

- **不用 iframe**：避免滚动同步、焦点陷阱、高度耦合三类问题。
- 隔离靠三点：① `[data-variant]` 作用域 CSS；② 每列一个独立 `state` 对象；③ 事件监听挂在列根，用 `data-*` 钩子分发。
- **全文件禁用 `id` 属性**（3 份重复 id 会互相污染），一律 `data-*` + `closest()` 定位。
- **渲染**：`render(panel)` 从 `state` 生成列表 DOM。插值**必须**经 `escapeHtml()`；示例第 08 条就是转义哨兵。
- **无 JS 一致性要求**：静态 DOM 是"无 JS 真相"；JS 的默认场景渲染结果必须与静态 DOM 视觉一致（同一面板宽度下截图对比，不得有可辨差异）。

### 8.5 明确禁止

- 禁止 `navigator.clipboard`、`clipboard.read*`、`document.execCommand('paste')`、`window.__TAURI__`、任何 `invoke`
- 禁止 `fetch` / `XMLHttpRequest` / `<img src="http...">` / `<link href="http...">` / 任何外部资源
- 禁止 `localStorage` / `sessionStorage`（预览状态只在内存里，刷新即回默认）
- 禁止把示例内容直接拼进 `innerHTML` 而不转义
- 禁止重绘或改造应用图标、生成字标

## 9. 状态与边界处理

### 9.1 错误态

- **粘贴失败**：列表上方一行 `粘贴失败：目标窗口未响应`，颜色 `--danger`，字号 11px，`padding: 0 4px`（复刻 `ContinuousPasteBar.tsx:215`）。
- **步进热键不可用**：执行阶段横幅下方一行 `步进热键不可用（可能与唤出热键冲突或被占用），请使用「粘贴下一条」按钮，或在设置中更换连续粘贴热键`，颜色 `--warn-text`。
- 两者都出现在 S12，且**不得遮挡**列表与状态栏。
- 预览内的失败注入：S12 场景由场景切换器直接置位，不做随机故障注入（保证可复现）。

### 9.2 无数据态

- 4 个空状态（S2–S5）+ 加载态（S6）文案**逐字复刻** `ClipboardList.tsx:100-147`，不新增文案、不改标点。
- 空状态在 3 套风格下的差异只在：图标尺寸、留白、行距、颜色；**结构（图标 → 标题 → 描述 → 可选按钮）不变**。
- S2 的「清空搜索」按钮点击后：搜索框清空、场景回到 S1、状态栏计数恢复 12。

### 9.3 窄屏

| 面板宽度 | 要求 |
|---|---|
| 320px（< 22.5rem） | 状态栏隐藏「存储大小」与版本号；列表左右 padding 8px；页签横向滚动（滚动条 4px）；连续粘贴横幅按钮组换行；设置模态 `margin: 0 12px`；**无横向滚动条、无文字溢出容器** |
| 420px（默认） | 全部信息可见 |
| 520px / 600px（≥ 32.5rem） | 行高 +8px；字号 +0.5~1px；列表 padding 16px；状态栏显示存储大小 |
| 预览器视口 < 1100px | 3 列纵向堆叠，每列面板居中，面板自身宽度不变 |

### 9.4 键盘

- **Tab 顺序**（每列内）：列头控件 → 标题栏按钮 → 搜索框 → 分组页签 → 连续粘贴横幅按钮（若存在）→ 列表行 → 状态栏控件。
- **焦点可见**：`:focus-visible` 用各风格的强调色 2px 外描边 + 2px 偏移；**不得移除 outline 而不给替代**。
- `Enter` / `Space` 激活条目＝单击语义。
- `Ctrl+F` 聚焦搜索框并 `preventDefault()`。
- `Escape` **分层**（严格照抄生产语义）：
  1. 行内删除确认打开 → 取消它；
  2. 设置模态打开 → 关模态（若「清空历史」确认开着，先关确认）；
  3. 搜索框聚焦 → 清空并失焦；
  4. 都不满足 → 不处理。
  **禁止全局单点处理 Escape**。
- 框选模式 + 焦点在 `body` + `Enter` → 开始连续粘贴（进入 S10）。
- **不做**列表内方向键移动焦点（与生产实现一致，属非目标）。

### 9.5 无 JS

- `<html>` 初始带 `class="no-js"`；`<script>` 第一行立即替换为 `class="js"`。
- `.no-js [data-requires-js] { display: none }`：无 JS 时隐藏场景切换器、主题切换、宽度切换、以及所有依赖 JS 的控件。
- 无 JS 时每列显示**完整默认场景**（S1 的 12 行 + 页签 + 搜索框 + 状态栏），外加一行提示：`本预览的交互需要 JavaScript；当前为静态展示。`
- 用 `<noscript>` 承载该提示，保证提示本身不依赖 JS。
- 无 JS 下：不得出现空白列、不得出现错位、不得出现横向滚动。
