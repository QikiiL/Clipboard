剪贴板 · 两套风格变体（A 瑞士索引 / C 雾绿工作台）

本页只有 A / C 两套（用户拍板后的最终版）。两列共用同一份布局骨架、同一份示例内容（10 条中性虚构示例）与同一套点击行为，差异只在视觉层。

每列独立状态：浅深两态各自成套（spec §4.1 令牌）、页签过滤、搜索、星标、行内删除确认、设置模态、活动日志互不干扰。列头的「浅色 / 深色」按钮与设置模态里的「深色模式」开关联动本列。

示例内容全部硬编码，不读取真实剪贴板、不写系统剪贴板；界面标识是纯文本「剪贴板」，不使用任何 logo 或字标。禁用 JavaScript 时静态 DOM 即为完整默认场景。

瑞士索引

阶段 2 · 定稿

浅灰白底 · 贯穿全宽的分隔线 · 34px 两位序号栏 · 单一朱红只做定位 · 无阴影、无 pill、无侧边强调条

  • A1贯穿全宽的分隔线比卡片更利于快速扫描。怎么看：不读列头，能否一眼看出这是「索引」而不是卡片列表。
  • A2行左两位序号栏支持按位置记忆。怎么看：能否凭序号直接回到第 07 条。
  • A3单一朱红只做定位、不参与装饰。怎么看：红色是否只出现在选中页签、选中行序号、收藏星、焦点环四处。

雾绿工作台

阶段 2 · 定稿

浅矿物灰 + 雾绿 · 无描边、无侧边竖条 · 圆角 14px、60px 行高、1.7 行距、12px 行间隙 · 靠明度与柔和投影分层 · 低对比 pill

  • C1去掉描边、靠明度分层更柔和但不丢层级。怎么看：能不能找到「卡片边框」。
