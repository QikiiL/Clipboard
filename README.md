# Clipboard · 剪贴板管理器

一个为 Windows 打造的剪贴板历史管理工具:复制过的内容自动留档,热键唤出、单击即贴,可一键接管 `Win+V` 替代系统剪贴板历史。基于 Tauri 2 + React 19 + Rust 构建,数据全部保存在本地,不依赖账号、不做云同步;除"检查更新"外不发起任何网络请求。

## 比 Windows 原生 Win+V 强在哪

Windows 10/11 自带的剪贴板历史(`Win+V`)上限 25 条、不支持文件类型、数据难以导出。本工具保持同样的"热键唤出、点击即贴"体验,同时补齐短板:

| 能力 | 剪贴板管理器 | Windows 原生 Win+V |
| --- | --- | --- |
| 历史上限 | 默认 500 条,可自由调整甚至无限制 | 固定 25 条 |
| 文件类型(资源管理器多选复制) | ✅ 支持,原样粘贴回 | ❌ 不支持 |
| 重启后保留 | ✅ 全部历史保留在本地 | 仅"固定"的条目 |
| 分组归类 | ✅ 自定义分组 + 收藏 | ❌ 仅固定置顶 |
| 搜索 | ✅ 实时防抖全文搜索 | 简单筛选 |
| 数据备份/迁移 | ✅ 标准 SQLite + 图片文件夹,拷贝目录即完成 | ❌ 系统加密存储,无法导出 |
| 存储位置 | ✅ 任意自定义(含程序目录便携模式) | 固定系统目录 |
| 云同步与账号 | 不需要、不上传,隐私可控 | 可选微软云同步 |
| 清理策略 | ✅ 按保留天数/最大条数自动清理,收藏豁免 | 手动清空 |
| 界面 | ✅ 尺寸位置自动记忆、窗口置顶、深浅双主题 | 固定面板 |
| 快捷键 | ✅ 任意自定义,或一键接管 Win+V | 仅 Win+V |
| 隐私排除 | ✅ 按来源进程 / 正则 / 敏感识别跳过入库 | ❌ 无 |

## 核心亮点

- **四类内容全支持**:文本、链接、图片(PNG 本地存档)、文件(资源管理器多选复制,原样粘贴回去)——文件类型是原生 Win+V 做不到的
- **单击即贴**:点击条目自动把焦点还原到唤出前的窗口并模拟 `Ctrl+V`,一气呵成;资源管理器等不便触发粘贴的场景可切"仅复制"模式
- **极致后台占用**:窗口隐藏即彻底销毁浏览器进程,内存全额归还系统,常驻后台仅约 10 MB——再次热键唤出约 1 秒重建,换来几乎为零的闲置开销
- **一键接管 Win+V**:设置里打开开关即可,禁用系统剪贴板历史、注册按键、刷新资源管理器全部自动完成,立即生效,无需重启电脑;偶发按键被系统占用时会自动回退 `Ctrl+Shift+V` 并提示稍后重试
- **绿色便携布局**:配置(`config/`)与数据(`data/`)都在程序目录下,整个文件夹拷到 U 盘即完成迁移;覆盖安装与升级自动保全这两个目录
- **内置更新检查**:启动时自动检查新版本(设置里也可手动检查),提供 GitHub 与蓝奏云两个下载入口,浏览器下载后覆盖安装,数据自动保留
- **智能去重与清理**:SHA-256 内容去重(重复复制只刷新时间),按天数/条数每小时自动清理过期记录并同步删除图片文件,收藏豁免
- **排除规则(隐私)**:命中规则的内容**不写入历史**,直接丢弃。三种依据可叠加:
  - **来源进程** —— 填可执行文件名。已预置 KeePass / KeePassXC / 1Password / Bitwarden,从密码管理器复制的密码默认不落盘
  - **内容正则** —— 自定义 Rust 正则,匹配整段内容(文件类型按路径列表匹配)
  - **敏感信息自动识别**(默认开启)—— 信用卡号、身份证号、PEM 私钥、AWS / GitHub / Slack 令牌、JWT、Bearer、Google API Key

  信用卡号需通过 Luhn 校验、身份证号需通过校验位验证才拦截,避免把订单号、时间戳误判成卡号。命中时状态栏显示「已排除」提示,便于确认规则是否符合预期

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Shift+V`(默认,可自定义) | 显示/隐藏主窗口 |
| `Win+V`(可选接管) | 同上,替代系统剪贴板历史 |
| `Ctrl+F` | 聚焦搜索框 |
| `Esc` | 清空搜索 / 关闭弹窗 |

## 安装与使用

- **安装版**:运行 `clipboard-setup.exe` 按引导完成(中文界面,默认安装到 `clipboard\` 文件夹)
- **便携版**:新建任意文件夹放入 `clipboard-manager-tauri.exe` 直接运行,`config/` 与 `data/` 自动生成在同目录
- 首次使用建议:设置里开启"开机自启动"(最小化到托盘);想用 `Win+V` 唤出就打开"替代系统 Win+V"开关,一步完成接管

> 应用以管理员权限运行(启动时弹 UAC 确认)——这是向管理员窗口粘贴、接管 `Win+V` 所必需的。

## 数据存储与隐私

```
clipboard/                  ← 程序文件夹
├── clipboard-manager-tauri.exe
├── config/                 ← settings.json、存储位置指针、窗口状态
└── data/                   ← clipboard.db(SQLite)、images/(PNG)
```

- 全部数据明文存于本地,备份 = 复制 `config/` 与 `data/` 两个文件夹
- 存储位置可在设置中改到任意目录(如独立数据盘),重启后自动迁移、失败自动回退
- 应用不依赖账号与云端;唯一的网络行为是访问版本信息文件检查更新
- 卸载时数据自动移至程序目录同级的 `clipboard-userdata\` 保全,可自行删除

## 从源码构建

前置要求:[Node.js](https://nodejs.org/) ≥ 20、[Rust](https://www.rust-lang.org/) stable、Windows 10/11。

```bash
npm install         # 安装依赖
npm run tauri dev   # 开发模式(热重载)
npm run tauri build # 产出 NSIS 安装包
npm test            # 前端测试
```

> Windows 下若使用 GNU 工具链,`src-tauri/.cargo/config.toml` 已包含 mingw 链接器配置;一键打包脚本见 `build-release.bat`,内存测量脚本见 `measure-mem.ps1`。

## 架构概览

- **前端** `src/`:React 19 + TypeScript + Tailwind CSS v4 + Zustand,CSS 变量深浅主题
- **后端** `src-tauri/`:Rust + Tauri 2。`arboard`/`clipboard-win` 轮询剪贴板(含 CF_HDROP 文件列表),`enigo` 模拟粘贴,`sqlx` 写 SQLite(WAL 模式,前后端双连接事件驱动),SHA-256 去重,每小时后台清理
- **窗口策略**:主窗口"隐藏即销毁、唤出即重建"(WebView2 进程树随隐藏退出),热键/托盘/命令统一走 `window_manager`;窗口几何由移动/缩放事件实时持久化,默认尺寸 461×569 物理像素
- **安装器**:NSIS 中文界面,内置数据保全钩子(覆盖安装/卸载前自动备份 `config`/`data`)

## 已知限制

- 仅支持 Windows(剪贴板文件格式、焦点还原与粘贴模拟均为 Windows 实现)
- 为换取约 10 MB 的后台占用,热键唤出需约 1 秒重建窗口(首次冷启动略久)
- 暂不支持多条内容批量粘贴
- 排除规则的「来源进程」一项,在**复制方程序已退出**时无法判定来源,该条不生效(Windows 剪贴板 API 的限制,同类工具同样如此);内容正则与敏感识别不受影响

## 发布新版本(维护者指南)

1. 更新 `tauri.conf.json` 与 `package.json` 中的版本号,运行 `build-release.bat` 打包
2. 编辑仓库根目录的 `version.json`(版本号、更新说明、GitHub 与蓝奏云下载页地址),推送到 GitHub 仓库(更新检查地址:`raw.githubusercontent.com/QikiiL/Clipboard/master/version.json`,见 `src-tauri/src/commands/update.rs`)
3. 新安装包分别上传到 GitHub Releases 和蓝奏云——已装用户启动应用即收到更新提醒
