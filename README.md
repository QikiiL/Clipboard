# Clipboard · 剪贴板管理器

一个为 Windows 打造的剪贴板历史管理工具:复制过的内容自动留档,热键唤出、单击即贴,可一键接管 `Win+V` 替代系统剪贴板历史。基于 Tauri 2 + React 19 + Rust 构建,数据全部保存在本地,不依赖账号、不做云同步;除"检查更新"外不发起任何网络请求。

## 比 Windows 原生 Win+V 强在哪

Windows 10/11 自带的剪贴板历史(`Win+V`)上限 25 条、不支持文件类型、数据难以导出。本工具保持同样的"热键唤出、点击即贴"体验,同时补齐短板:

| 能力 | 剪贴板管理器 | Windows 原生 Win+V |
| --- | --- | --- |
| 历史上限 | 默认 500 条,可自由调整甚至无限制 | 固定 25 条 |
| 文件类型(资源管理器多选复制) | ✅ 支持,原样粘贴回 | ❌ 不支持 |
| 重启后保留 | ✅ 全部历史保留在本地 | 仅"固定"的条目 |
| 分组归类 | ✅ 自定义分组 + 收藏 | ❌ 仅固定置顶 |
| 搜索 | ✅ 实时防抖全文搜索 | 简单筛选 |
| 数据备份/迁移 | ✅ 标准 SQLite + 图片文件夹,拷贝目录即完成 | ❌ 系统加密存储,无法导出 |
| 存储位置 | ✅ 任意自定义(含程序目录便携模式) | 固定系统目录 |
| 云同步与账号 | 不需要、不上传,隐私可控 | 可选微软云同步 |
| 清理策略 | ✅ 按保留天数/最大条数自动清理,收藏豁免 | 手动清空 |
| 界面 | ✅ 尺寸位置自动记忆、窗口置顶、深浅双主题 | 固定面板 |
| 快捷键 | ✅ 任意自定义,或一键接管 Win+V | 仅 Win+V |

## 核心亮点

- **四类内容全支持**:文本、链接、图片(PNG 本地存档)、文件(资源管理器多选复制,原样粘贴回去)——文件类型是原生 Win+V 做不到的
- **单击即贴**:点击条目自动把焦点还原到唤出前的窗口并模拟 `Ctrl+V`,一气呵成;资源管理器等不便触发粘贴的场景可切"仅复制"模式
- **极致后台占用**:窗口隐藏即彻底销毁浏览器进程,内存全额归还系统,常驻后台仅约 10 MB——再次热键唤出约 1 秒重建,换来几乎为零的闲置开销
- **一键接管 Win+V**:设置里打开开关即可,禁用系统剪贴板历史、注册按键、刷新资源管理器全部自动完成,立即生效,无需重启电脑;偶发按键被系统占用时会自动回退 `Ctrl+Shift+V` 并提示稍后重试
- **绿色便携布局**:配置(`config/`)与数据(`data/`)都在程序目录下,整个文件夹拷到 U 盘即完成迁移;覆盖安装与升级自动保全这两个目录
- **内置更新检查**:启动时自动检查新版本(设置里也可手动检查),提供 GitHub 与蓝奏云两个下载入口,浏览器下载后覆盖安装,数据自动保留
- **智能去重与清理**:SHA-256 内容去重(重复复制只刷新时间),按天数/条数每小时自动清理过期记录并同步删除图片文件,收藏豁免
- **排除规则**:按来源软件、自定义规则、内置敏感识别(密钥 / 令牌 / 信用卡号 / 身份证号)三层判定,命中的内容不落盘;卡号还校验发卡行前缀,误报率低;万一看走眼,提示上点「仍要记录」就能补录
- **敏感内容提醒**:内容被拦截时屏幕正中弹提示;应用不在前台的话,Windows 通知中心也会提醒,不会"悄悄丢了东西还不知道"

## 排除规则

有些内容不该进剪贴板历史——密码、密钥、银行卡号。开启后,这些内容在入库前就跳过,不写数据库、不生成预览。判定分三层,任意一层命中即跳过:

| 层级 | 依据 | 说明 |
| --- | --- | --- |
| 来源软件 | 复制方的进程名 | 预置 KeePass / KeePassXC / 1Password / Bitwarden,可自行增删 |
| 自定义规则 | 你填的文字或格式 | 直接写字(如 `内部机密`),也可写格式规则(如 `订单号[0-9]+`) |
| 内置敏感识别 | 10 类已知格式 | 私钥、AWS / GitHub / Slack 令牌、JWT、信用卡号、身份证号等,可一键关闭 |

### 误报控制

误杀一条正常内容,比漏掉一条密钥更让人恼火——前者会直接毁掉对工具的信任。所以做了三件事:

- **卡号不只看格式**。除 Luhn 校验外,还校验发卡行前缀(Visa / 万事达 / 银联 / Amex 等)和该品牌对应的卡号长度。30 万随机数字样本实测,误报率从 9.93% 降到 1.72%——银行账号、IMEI、订单号这类长数字基本不会再被误判成卡号。
- **身份证号必过校验位**,光按格式匹配会误伤大量普通数字。
- **刻意不做** `password: xxx` 这类"关键词 + 值"的通用匹配。代码和配置文件里 `password` 字样出现的频率远高于真实密码泄漏,这么做会误报满天飞,最后只能把功能整个关掉。

### 误判了怎么办

被拦下的内容会在**屏幕正中**弹提示,带两个按钮:

- **仍要记录** —— 补录进历史,并加入豁免名单,以后再复制也不拦
- **知道了** —— 维持拦截,提示 8 秒后自动消失

豁免名单在设置里能看到条数、随时清空。

> 注意:被排除的内容即使再复制一次也不会重新提示(去重逻辑导致),所以这 8 秒是唯一的补救窗口——好在提示在正中间,不会错过。

### 敏感内容提醒

应用**不在前台**时(你正在浏览器、IDE 或聊天窗口里),拦截发生会往 Windows 通知中心推一条提醒,标题「剪贴板内容已拦截」。应用在前台时只弹应用内提示,不重复打扰。

功能边界见[已知限制](#已知限制),安全设计细节见 [`docs/SECURITY-AUDIT.md`](docs/SECURITY-AUDIT.md) 的 F-4。

## 安装与使用

- **安装版**:运行 `clipboard-setup.exe` 按引导完成(中文界面,默认安装到 `clipboard\` 文件夹)
- **便携版**:新建任意文件夹放入 `clipboard-manager-tauri.exe` 直接运行,`config/` 与 `data/` 自动生成在同目录
- 首次使用建议:设置里开启"开机自启动"(最小化到托盘);想用 `Win+V` 唤出就打开"替代系统 Win+V"开关,一步完成接管

> 应用以管理员权限运行(启动时弹 UAC 确认)——这是向管理员窗口粘贴、接管 `Win+V` 所必需的。

## 数据存储与隐私

```
clipboard/                  ← 程序文件夹
├── clipboard-manager-tauri.exe
├── config/                 ← settings.json、存储位置指针、窗口状态
└── data/                   ← clipboard.db(SQLite)、images/(PNG)
```

- 全部数据明文存于本地,备份 = 复制 `config/` 与 `data/` 两个文件夹
- 存储位置可在设置中改到任意目录(如独立数据盘),重启后自动迁移、失败自动回退
- 应用不依赖账号与云端;唯一的网络行为是访问版本信息文件检查更新
- 卸载时数据自动移至程序目录同级的 `clipboard-userdata\` 保全,可自行删除

## 从源码构建

前置要求:[Node.js](https://nodejs.org/) ≥ 20、[Rust](https://www.rust-lang.org/) stable、Windows 10/11。

```bash
npm install         # 安装依赖
npm run tauri dev   # 开发模式(热重载)
npm run tauri build # 产出 NSIS 安装包(需本机安装 NSIS)
npm test            # 前端测试
```

**工具链:用 GNU,不是 MSVC。** 项目按 `stable-x86_64-pc-windows-gnu` 构建,
`src-tauri/.cargo/config.toml` 已包含 mingw 链接器配置。若环境里设了
`RUSTUP_TOOLCHAIN` 指向 MSVC 会编译失败(本机未装 MSVC 构建工具)。

| 脚本 | 用途 |
| --- | --- |
| `dev-gnu.bat` | 双击即可编译并打开应用。自动申请管理员权限(接管 `Win+V`、向管理员窗口粘贴都需要),并锁定 GNU 工具链。日常开发/自测用它 |
| `build-release.bat` | 一键打包。注意它会先加载 MSVC 环境,但 Rust 侧仍走 rustup default(GNU),那句 `vcvars64` 是历史遗留 |
| `measure-mem.ps1` | 后台内存占用测量 |

> **打包需要 [NSIS](https://nsis.sourceforge.io/)。** 没装的话 `tauri build` 会在最后的打包步骤失败,但 `src-tauri/target/release/clipboard-manager-tauri.exe` 已经生成——直接拷出来放进空文件夹就是便携版,首次运行会自动在同目录建立 `config/` 和 `data/`。

## 架构概览

- **前端** `src/`:React 19 + TypeScript + Tailwind CSS v4 + Zustand,CSS 变量深浅主题
- **后端** `src-tauri/`:Rust + Tauri 2。`arboard`/`clipboard-win` 轮询剪贴板(含 CF_HDROP 文件列表),`enigo` 模拟粘贴,`sqlx` 写 SQLite(WAL 模式,前后端双连接事件驱动),SHA-256 去重,每小时后台清理;`tauri-plugin-notification` 发系统通知,`exclusion_service` 做入库前的排除判定
- **窗口策略**:主窗口"隐藏即销毁、唤出即重建"(WebView2 进程树随隐藏退出),热键/托盘/命令统一走 `window_manager`;窗口几何由移动/缩放事件实时持久化,默认尺寸 461×569 物理像素
- **安装器**:NSIS 中文界面,内置数据保全钩子(覆盖安装/卸载前自动备份 `config`/`data`)

## 已知限制

- 仅支持 Windows(剪贴板文件格式、焦点还原与粘贴模拟均为 Windows 实现)
- 为换取约 10 MB 的后台占用,热键唤出需约 1 秒重建窗口(首次冷启动略久)
- 暂不支持多条内容批量粘贴
- 排除规则的「来源软件」在复制方进程已退出时无法判定(此时该条不生效,另两类规则照常),这是所有剪贴板管理器的共同限制
- 内置敏感识别定位是「已知格式密钥 + 密码管理器」拦截,**不覆盖**从聊天窗口、Excel、终端等非密码管理器来源复制的明文密码,也不覆盖 `db_password: xxx`、`.env` 这类配置文件式凭据;有需要可在设置里自行加正则(详见 `docs/SECURITY-AUDIT.md` 的 F-4)
- 点击 Windows 通知**不会自动唤起应用窗口**:Tauri 2 的通知插件没有提供点击回调,Windows 的 AUMID 激活机制在部分场景下也不生效。通知只负责提醒,需要你手动打开应用处理

## 发布新版本(维护者指南)

1. 更新版本号,共 3 处必须一致:`package.json`、`src-tauri/tauri.conf.json`、`src-tauri/Cargo.toml`(应用内更新检查和状态栏版本显示都读它们),然后运行 `build-release.bat` 打包
2. 编辑仓库根目录的 `version.json`(版本号、更新说明、GitHub 与蓝奏云下载页地址),推送到 GitHub 仓库(更新检查地址:`raw.githubusercontent.com/QikiiL/Clipboard/master/version.json`,见 `src-tauri/src/commands/update.rs`)
3. 新安装包分别上传到 GitHub Releases 和蓝奏云——已装用户启动应用即收到更新提醒
